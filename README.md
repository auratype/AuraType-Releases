## Core Engine Features

AuraType is built to simulate physical keystrokes accurately. Unlike standard text macros that paste instantly and break layouts, AuraType interacts directly with the active window layout:

*   **Adaptive Timing**
    Types text with a natural, human-like rhythm so each keystroke feels genuinely typed, not automated.
*   **Clipboard Mode**
    Delivers long text blocks in an instant, bypassing keystroke limits for speed-critical workflows.
*   **Code Mode**
    Preserves indentation, spacing, and brackets when typing into web-based code editors.
*   **Clean Output**
    Clears the target field before typing starts and hands focus back when done. No stray text is left behind.
*   **Windows Compatibility**
    Built natively for Windows 10 and 11, tested across a wide range of applications out of the box.

## Reliability & Security

*   **Modifier Key Neutralization**
    Automatically releases physically held down modifier keys (Shift, Ctrl, Alt, Win) before starting typing, ensuring automated shortcuts execute cleanly without key interference.
*   **Secure Local Vault**
    Saved keyboard automation profiles and records are encrypted and saved locally to your device.
*   **Razorpay Integration**
    Checkout and purchases are processed directly through Razorpay. We do not store or handle credit card details.
*   **Trusted Signing Certificate**
