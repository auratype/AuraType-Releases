## Core Engine Features

AuraType simulates physical keystrokes with precision. Unlike standard clipboard tools that paste all at once and break form formatting, AuraType interacts directly with the active window:

*   **Adaptive Timing**
    Types text with a natural, human-like rhythm so each keystroke feels genuinely typed.
*   **Clipboard Mode**
    Delivers long text blocks instantly with a single hotkey, bypassing keystroke limits for speed-critical workflows.
*   **Smart Code Mode**
    Preserves indentation, line breaks, and brackets when typing into web-based code environments and terminal windows.
*   **Clean Output**
    Clears the target field before typing starts and hands focus back when done, leaving zero stray text behind.
*   **Zero-Interference Hotkeys**
    Automatically neutralizes held modifier keys (Shift, Ctrl, Alt, Win) before triggering to prevent key collisions.

## Reliability & Security

*   **Official Microsoft Store Certified**
    The Windows desktop edition is verified and distributed through the Microsoft Store. Clean installation, zero Windows Defender/SmartScreen false positives, and automatic background updates.
*   **Secure Local Vault**
    Saved records and hotkey configurations are encrypted and stored locally on your device in `%APPDATA%\AuraType`. No keystroke data is ever uploaded or synced.
